# Checkpoint 日本語版

3DS向けの非公式日本語版。日本語版制作：yu_

2026-10-26：日本語の初期設定、訳文、表示名を変更しました。

[CIA](https://github.com/Yu08083/Checkpoint-JP/releases/latest/download/Checkpoint.cia) をFBIでインストールしてください。[3DSX](https://github.com/Yu08083/Checkpoint-JP/releases/latest/download/Checkpoint.3dsx) も配布しています。

既存の設定で英語になる場合は、Settings → General → Language で「日本語」を選んでください。Automatic updates は無効にしてください。

CIA版は公式版を置き換えます。セーブと設定の保存先は `/3ds/Checkpoint/` です。

原作者：[Bernardo Giordano・FlagBrew](https://github.com/BernardoGiordano/Checkpoint) および各貢献者。元の著作権表示とGPLv3以降のライセンス、追加条項7.b・7.cを保持しています。
